#### Commands

Install dependencies

```
$ yarn
```

Serve

```
$ yarn start
```

Build

```
$ yarn build
```

Clean

```
$ yarn clean
```

## Running locally

Install the dependencies by running `yarn` in the project root. Then run `yarn start` to serve the game locally with http-server, and open the local URL it prints in your browser.
